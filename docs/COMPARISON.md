# Похожие проекты и удобство

Проверено 4 ноября 2026 года по публичным исходникам и инструкциям проектов. Для Deck AI проверка на Steam Deck описана в релизе. Сравнение остальных проектов основано на их документации.

## Сравнение

| Проект | В чём похож | Первое использование | Удалённое управление | Отличие от Deck AI |
|---|---|---|---|---|
| **[Quest Compendium](https://github.com/TuriusX/Quest-Compendium-Decky)** | Decky, игровой контекст, снимок экрана, история, полный экран | Ручная установка ZIP/URL. Есть гостевые вопросы без входа; Premium подключается QR-кодом | В README описан игровой помощник, а не агент для команд на другом компьютере | Самый близкий аналог по месту использования. Готовые вопросы и гостевой режим сокращают путь до первого ответа. Запросы идут через сервер проекта к Gemini; лимиты и Premium определяет сервис |
| **[Happy](https://github.com/slopus/happy)** | Claude/Codex, продолжение чатов, уведомления и управление агентом со второго устройства | CLI требует Node и установленного агента; `happy codex`/`happy claude` показывает QR. Есть отдельное настольное приложение | Мобильный/веб-клиент, фоновый daemon, relay; заявлены E2EE и совместные сессии | Ближе всего по удалённой работе. QR и готовые клиенты удобнее нашей первоначальной настройки SSH. В изученных инструкциях нет нативного Decky-интерфейса |
| **[HAPI](https://github.com/tiann/hapi)** | Официальные агенты, чаты, файлы, терминал, подтверждения, уведомления | Нужны агент, hub и CLI; hub выдаёт URL/QR. Для создания сессий удалённо используется runner | Бесплатный Web/PWA; платные готовые iOS/Android-клиенты. Есть relay и самостоятельное размещение | Богаче документированный удалённый сценарий, но больше компонентов для обслуживания. Не является готовой панелью Decky |
| **Deck AI** | Чат Codex и диагностика запуска игры прямо на Deck | Графический установщик, собственный вход в Codex. Claude настраивается в официальном CLI. Установка через GitHub | Полный доступ к Codex с Mac/ПК по SSH. HTTPS-пульт с QR для подтверждения одного ремонта в браузере | Панель Quick Access и отдельное приложение Desktop Mode. Для пульта требуется свой HTTPS-адрес, для доступа извне требуется доступная частная сеть |

Подробности установки и QR у [Happy CLI](https://github.com/slopus/happy/blob/main/packages/happy-cli/README.md), компонентов у [HAPI](https://github.com/tiann/hapi/blob/main/docs/guide/installation.md). У HAPI совместная работа с Codex имеет [ограничения жизненного цикла](https://github.com/tiann/hapi/blob/main/docs/guide/codex-shared-sessions.md): закрытие исходного терминала завершает принадлежащий ему движок; восстановление требует доступного runner и прежнего хранилища. Наличие функции в README не означает, что она работает без подготовки в любом окружении.

## Вывод для проекта и ролика

В ролике можно показать связку **панель Decky → диагностика запуска → подтверждение с телефона → проверка и откат в Steam**. В Happy и HAPI QR открывает доступ к работе с агентом, а в Deck AI QR даёт доступ к одному ремонту. Для работы с чатами Deck AI использует SSH.

Бесплатность клиента не означает бесплатность модели. У Deck AI расходы определяет доступ пользователя; Quest использует собственные квоты/Premium, HAPI отдельно различает бесплатный веб-клиент и платные готовые мобильные приложения. Условия могут измениться.

Следующие улучшения по приоритету:

1. Упростить первое подключение именно к чатам Codex. Проверить прототип с QR или ссылкой и обязательной сверкой устройства. Для ремонта одноразовое QR уже реализовано.
2. Единый экран готовности: CLI, вход, Decky, доступность второго устройства и понятное восстановление после сна.
3. Кнопки типовых первых задач и короткая пробная команда, чтобы новичок сразу увидел результат.
4. Независимая установка на чистом Deck и ручная проверка геймпада, сна/пробуждения и микрофона в игре. Количество unit-тестов не заменяет эти проверки.

В rc.9 уже исправлен отдельный барьер Claude: официальный вход без перехвата токенов, сохранение собственных API/cloud-настроек, отдельный Console/API-путь и понятное описание оплаты. [Инструкция](CLAUDE-AUTH.md).

Deck AI не принят в официальный каталог Decky; причины и ссылка на решение опубликованы в [статусе подачи](DECKY-SUBMISSION.md). Ручная установка конкурента тоже не означает одобрения каталогом.
